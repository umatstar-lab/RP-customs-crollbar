# RP Custom Scrollbar — Joomla 6

Пользовательская доработка RP Custom Scrollbar 1.0.0 для Joomla 6. Требования: Joomla 6.0+ и PHP 8.3+.

## Скачать

[Установочный ZIP 1.1.1](https://github.com/umatstar-lab/RP-customs-crollbar/raw/refs/heads/main/dist/rp-custom-scrollbar-joomla6-1.1.1.zip)

[ZIP из репозитория](https://github.com/umatstar-lab/RP-customs-crollbar/raw/refs/heads/main/dist/rp-custom-scrollbar-joomla6-1.1.1.zip) · [Отчёт и инструкция](docs/verification-1.1.0.ru.md) · [SHA-256](dist/SHA256SUMS.txt)

Загрузите ZIP через установщик расширений Joomla. Для обновления установите поверх версии 1.0.0, не удаляя её предварительно: настройки и состояние включения сохраняются. При новой установке включите плагин в менеджере плагинов.

Языки интерфейса: английский, русский и украинский. Язык выбирается автоматически по языку панели управления Joomla; соответствующий языковой пакет Joomla должен быть установлен.

## Изменения

Современные API Joomla 6, строгая фильтрация настроек при сохранении и перед выводом, устранение CSS-инъекции и ошибок при отключении рамок. Добавлены стандартные цвета для Firefox. Внешний устаревший сервер обновлений удалён; следующие сборки устанавливаются вручную.

Полная CMS проверена на Joomla 6.0.0 и 6.2.0 с PHP 8.3.36. Отдельные проверки нормализации/CSS выполнены на PHP 8.3.11, 8.4.1 и 8.5.2 (WASM). Точная стилизация зависит от браузера и ОС.

## Разработка

Все изменения этого плагина ведутся в этом репозитории. Исходники плагина находятся в корне, пакеты — в `dist/`, проверки — в `tests/`.

```sh
npm ci
npm test
python3 tools/build.py
```

Интеграционные проверки запускаются только на одноразовой установленной Joomla с установленным плагином и доступной тестовой БД:

```sh
JOOMLA_ROOT=/path/to/disposable-joomla SCROLLBAR_TEST_DB=1 php tests/integration.php site
JOOMLA_ROOT=/path/to/disposable-joomla SCROLLBAR_TEST_DB=1 php tests/integration.php administrator
```

Эти проверки отключают плагины обратной совместимости в указанной тестовой БД. Не запускайте их на рабочем сайте.
