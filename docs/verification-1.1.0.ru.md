# RP Custom Scrollbar 1.1.0 — Joomla 6

Исправленная пользовательская сборка исходного RP Custom Scrollbar 1.0.0. Не является официальным релизом первоначального автора.

## Установка / обновление

1. Сделайте резервную копию сайта и базы данных.
2. В Joomla откройте «Система → Установка → Расширения» и загрузите `rp-custom-scrollbar-joomla6-1.1.0.zip` целиком, без распаковки.
3. При обновлении не удаляйте старую версию заранее: идентификатор и названия параметров сохранены, настройки и состояние включения переходят в новую версию.
4. После новой установки включите «System - RP Custom Scrollbar» в списке плагинов. После обновления проверьте сайт и админку; при необходимости очистите кеш Joomla.

Требования: Joomla 6.0+ и PHP 8.3+. Эта сборка предназначена для Joomla 6, установка на Joomla 3–5 не поддерживается. На Joomla 7 тестирование не проводилось.

## Изменения

- Современный namespace, DI service provider, SubscriberInterface и типизированный BeforeCompileHeadEvent.
- Документ берётся из события, стили подключаются через Web Asset Manager. Устаревшие Factory::getDocument(), legacy listener и свойство $app исключены.
- CSS генерируется только для HTML-документов сайта и админки. API/CLI и JSON исключены.
- Строгая серверная фильтрация всех параметров при сохранении и повторная нормализация перед выводом; HTML-экранирование не используется вместо проверки CSS.
- Разрешены только одиночные неотрицательные размеры: px, em, rem, %, а также ноль. Ненулевые числа без единиц, CSS-функции, комментарии, URL и разделители запрещены. Ширина: до 200px / 10em / 10rem / 100%; радиус: до 1000px / 100em / 100rem / 100%. Цвета: #RGB или #RRGGBB. Стиль рамки — из фиксированного списка.
- Недопустимые значения заменяются безопасными значениями по умолчанию. Старые нестандартные значения могут визуально измениться после обновления.
- Исправлено закрытие всех CSS-блоков при отключении рамок.
- Добавлены стандартные цвета полосы прокрутки для Firefox и fallback для режима forced-colors. Точное оформление, ширина, рамки и hover зависят от возможностей браузера и ОС; одинаковый вид во всех браузерах не гарантируется.
- При обновлении удаляется старый rpcustomscrollbar.php и только привязка этого расширения к исходному устаревшему update.xml. Общий сервер удаляется лишь при отсутствии других привязок. Новый ZIP не содержит внешнего сервера обновлений: последующие пользовательские сборки устанавливаются вручную.
- GPL-лицензия и сведения об исходном авторе сохранены.
