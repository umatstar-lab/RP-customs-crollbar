# Локализации в версии 1.1.1

Добавлены ru-RU и uk-UA: по 47 ключей интерфейса и по 2 ключа системного описания. Переведены настройки, вкладки, варианты стиля рамки и ограничения браузеров. Названия параметров и значения стилей CSS сохранены.

Все 6 INI-файлов проверены PHP-парсером; наборы ключей совпадают, ссылки из манифеста разрешаются, языковые файлы присутствуют в установочном ZIP. Повторные проверки нормализации/CSS на PHP 8.3.11, 8.4.1 и 8.5.2 (WASM) прошли: по 3225 проверок. Полная установка CMS для этого изменения повторно не выполнялась; результаты предыдущей проверки находятся в verification-1.1.0.ru.md.

Язык определяется языком панели управления Joomla. Для русского интерфейса установите языковой пакет ru-RU, для украинского — uk-UA. Обновите плагин установкой ZIP поверх предыдущей версии.
