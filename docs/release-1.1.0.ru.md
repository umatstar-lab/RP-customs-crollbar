Пользовательская сборка RP Custom Scrollbar для Joomla 6.0+ / PHP 8.3+.

- Современная архитектура Joomla 6 и Web Asset Manager.
- Исправлена CSS-инъекция, добавлена фильтрация при сохранении и перед выводом.
- Исправлено оформление при отключённых рамках.
- Проверены установка на Joomla 6.0.0 / 6.2.0 и обновление с 1.0.0 с сохранением настроек.

Для установки скачайте прикреплённый `rp-custom-scrollbar-joomla6-1.1.0.zip` и загрузите через установщик Joomla. При обновлении не удаляйте старую версию. Архивы Source code, которые GitHub создаёт автоматически, не являются установочным пакетом.

Подробности и ограничения проверок: `docs/verification-1.1.0.ru.md`. Контрольная сумма — в приложенном `SHA256SUMS.txt`.
